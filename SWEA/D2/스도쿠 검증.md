## [문제]
스도쿠는 숫자퍼즐로, 가로 9칸 세로 9칸으로 이루어져 있는 표에 1 부터 9 까지의 숫자를 채워넣는 퍼즐이다.

<img width="263" height="235" alt="image" src="https://github.com/user-attachments/assets/8cf2cb0f-1a87-4d64-b32c-febf3a7df05d" />

같은 줄에 1 에서 9 까지의 숫자를 한번씩만 넣고, 3 x 3 크기의 작은 격자 또한, 1 에서 9 까지의 숫자가 겹치지 않아야 한다.

<img width="282" height="233" alt="image" src="https://github.com/user-attachments/assets/f384eceb-f849-42a9-a1ae-8751df72bfe5" />

입력으로 9 X 9 크기의 스도쿠 퍼즐의 숫자들이 주어졌을 때, 위와 같이 겹치는 숫자가 없을 경우, 1을 정답으로 출력하고 그렇지 않을 경우 0 을 출력한다.

 
## [제약 사항]
1. 퍼즐은 모두 숫자로 채워진 상태로 주어진다.
2. 입력으로 주어지는 퍼즐의 모든 숫자는 1 이상 9 이하의 정수이다.

## [입력]
입력은 첫 줄에 총 테스트 케이스의 개수 T가 온다.
다음 줄부터 각 테스트 케이스가 주어진다.
테스트 케이스는 9 x 9 크기의 퍼즐의 데이터이다.

입력
10
7 3 6 4 2 9 5 8 1
5 8 9 1 6 7 3 2 4
2 1 4 5 8 3 6 9 7
8 4 7 9 3 6 1 5 2
1 5 3 8 4 2 9 7 6
9 6 2 7 5 1 8 4 3
4 2 1 3 9 8 7 6 5
3 9 5 6 7 4 2 1 8
6 7 8 2 1 5 4 3 9
…

## [출력]
테스트 케이스 t에 대한 결과는 “#t”을 찍고, 한 칸 띄고, 정답을 출력한다.
(t는 테스트 케이스의 번호를 의미하며 1부터 시작한다.)

출력
#1 1
...


## [풀이]
```java
import java.util.Scanner;
import java.io.FileInputStream;

class Solution{
    public static void main(String args[]) throws Exception{
        Scanner sc = new Scanner(System.in);
        int T;
        T = sc.nextInt();
        
        for(int test_case = 1; test_case <= T; test_case++){
            int[][] arr = new int[9][9];
            
            // 1. 스도쿠 판 입력 받기
            for(int i = 0; i < 9; i++){
                for(int j = 0; j < 9; j++){
                    arr[i][j] = sc.nextInt();
                }
            }
            
            // 테스트 케이스마다 초기화
            boolean isValue = true; 
            
            // 2. 가로 줄(행) 검사
            for(int i = 0; i < 9; i++){
                boolean[] check = new boolean[10]; // boolean 배열로 수정
                for(int j = 0; j < 9; j++){
                    int num = arr[i][j];
                    if(check[num]){
                        isValue = false;
                    }
                    check[num] = true;
                }
            }
            
            // 3. 세로 줄(열) 검사
            for (int j = 0; j < 9; j++) {
                boolean[] check = new boolean[10];
                for (int i = 0; i < 9; i++) {
                    int num = arr[i][j];
                    if (check[num]) {
                        isValue = false;
                    }
                    check[num] = true;
                }
            }
            
            // 4. 3x3 작은 격자 검사
            for(int k = 0; k < 9; k += 3){
                for(int l = 0; l < 9; l += 3){
                    boolean[] check = new boolean[10]; // 배열 기호([]) 추가
                    for(int i = 0; i < 3; i++){
                        for(int j = 0; j < 3; j++){
                            int num = arr[k + i][l + j];
                            if (check[num]) {
                                isValue = false;
                            }
                            check[num] = true;
                        }
                    }
                }
            }
            
            int result = isValue ? 1 : 0;
            System.out.println("#" + test_case + " " + result);
        }
    }
}
```
