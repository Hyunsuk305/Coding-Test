## [문제]
N 개의 숫자로 구성된 숫자열 Ai (i=1~N) 와 M 개의 숫자로 구성된 숫자열 Bj (j=1~M) 가 있다.
아래는 N =3 인 Ai 와 M = 5 인 Bj 의 예이다.

<img width="260" height="132" alt="image" src="https://github.com/user-attachments/assets/3956a8dd-0a70-4ec1-a64e-40846f22804f" />

Ai 나 Bj 를 자유롭게 움직여서 숫자들이 서로 마주보는 위치를 변경할 수 있다.
단, 더 긴 쪽의 양끝을 벗어나서는 안 된다.

<img width="318" height="173" alt="image" src="https://github.com/user-attachments/assets/2042bb78-acb3-4f91-b4ca-4f608759a3a8" />

서로 마주보는 숫자들을 곱한 뒤 모두 더할 때 최댓값을 구하라.
위 예제의 정답은 아래와 같이 30 이 된다.

<img width="390" height="168" alt="image" src="https://github.com/user-attachments/assets/b3a90576-b3e6-4d7b-8991-9a1321666bea" />

## [제약 사항]
N 과 M은 3 이상 20 이하이다.

## [입력]
가장 첫 줄에는 테스트 케이스의 개수 T가 주어지고, 그 아래로 각 테스트 케이스가 주어진다.
각 테스트 케이스의 첫 번째 줄에 N 과 M 이 주어지고, 두 번째 줄에는 Ai, 세 번째 줄에는 Bj 가 주어진다.

입력
10
3 5
1 5 3
3 6 -7 5 4
7 6
6 0 5 5 -1 1 6
-4 1 8 7 -9 3
...  

## [출력]
출력의 각 줄은 '#t'로 시작하고, 공백을 한 칸 둔 다음 정답을 출력한다.
(t는 테스트 케이스의 번호를 의미하며 1부터 시작한다.)

출력
#1 30
#2 63
...

## [풀이]

```java
import java.util.Scanner;
import java.io.FileInputStream;

class Solution{
	public static void main(String args[]) throws Exception{
		Scanner sc = new Scanner(System.in);
		int T;
		T=sc.nextInt();
		for(int test_case = 1; test_case <= T; test_case++){
			int n = sc.nextInt();
            int m = sc.nextInt();
            int[] ai = new int[n];
            int[] bj = new int[m];
            int max = Integer.MIN_VALUE;
            
            for(int i = 0; i < n; i++){
            	ai[i] = sc.nextInt();
            }
            for(int j = 0; j < m; j++){
            	bj[j] = sc.nextInt();
            }
            
            if(n <= m){
                for(int k = 0; k <= m - n; k++){
                    int sum = 0;
                    for(int i = 0; i < n; i++){
                        sum += ai[i] * bj[i + k];
                    }
                    if(sum > max){
                        max = sum;
                    }
                }
            } else {
                for(int l = 0; l <= n - m; l++){
                	int sum = 0;
                    for(int j = 0; j < m; j++){
                        sum += ai[j+ l] * bj[j];
                    }
                    if(sum > max){
                    	max = sum;
                    }
                }
            }
            System.out.println("#" + test_case + " " + max);
		}
	}
}
```
