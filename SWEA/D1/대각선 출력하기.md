## [문제]
주어진 텍스트를 그대로 출력하세요.

## [출력]
#++++
+#+++
++#++
+++#+
++++#

## [풀이]

```java
import java.io.FileInputStream;
class Solution{
	public static void main(String args[]) throws Exception{
	 for(int i = 0; i < 5; i++){
       for(int j = 0; j < 5; j++){
           if(i == j){
              System.out.print("#");
            } else{
                System.out.print("+");
            }
        }
        System.out.println();
    }
	}
}
```
