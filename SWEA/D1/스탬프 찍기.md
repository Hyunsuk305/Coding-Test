## [문제]
주어진 숫자만큼 # 을 출력해보세요.
주어질 숫자는 100,000 이하다.

## [입력]
입력으로 자연수 N이 주어진다.

입력
3

## [출력]
#을 숫자만큼 출력한다.

출력
###

## [풀이]

```java
import java.util.Scanner;
import java.io.FileInputStream;

class Solution{
	public static void main(String args[]) throws Exception{

		Scanner sc = new Scanner(System.in);
		int T;
		T=sc.nextInt();
		for(int i = 0; i < T; i++){
        System.out.print("#");
    }
	}
}
```
